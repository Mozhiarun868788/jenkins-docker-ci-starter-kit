# Jenkins + Docker CI/CD Starter Kit

## Project Overview

This project demonstrates a simple, reusable CI/CD workflow using Jenkins and Docker.

## Goals

- Build a Docker image through a Jenkins pipeline.
- Run an automated container health check.
- Document setup and troubleshooting steps.
- Demonstrate basic security practices.
- Provide a beginner-friendly, reusable learning resource.

## Intended Audience

DevOps engineers, developers, and learners who want to understand a practical Jenkins and Docker workflow.

## Project Status

Version 0.1.0 — Initial development.

## Disclaimer

This is an independent learning project. It is not intended for production deployment without further review, testing, and security hardening.
